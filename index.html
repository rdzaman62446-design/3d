Two ways in

Floor plan mode

Walls, doors and windows to exact size

Click out walls on a millimetre grid, or type each length. Drop doors and windows onto walls and set their width, height and sill. Have a scanned plan? Put it behind the grid, set the scale from one known dimension and trace over it.

  • Angle snapping at 45° and joined corners
  • Wall height and thickness per wall
  • Save and reopen plans as .json

Multi-view mode

Front, side and top views carved into a solid

Upload up to six orthographic views: front, back, left, right, top and bottom. Draft3D finds each silhouette and keeps only the shape that matches every view, then smooths it into a mesh at the real size you enter.

  • Works for people, products and furniture
  • Fills line drawings and ignores labels
  • Warns when views are drawn at different scales
Open multi-view mode

What your drawings need

Accurate drawings give accurate models. For multi-view carving, every view has to describe the same object in the same way.

  1. One scale for every view. The figure is the same height in the front and side views.
  2. Lined up. Head, shoulders and feet sit at the same level in each view.
  3. One pose. For people, a T-pose or A-pose keeps arms clear of the body.
  4. Straight-on views. Orthographic, with no perspective.
  5. A clean background. Dark lines or fill on light paper, or a transparent PNG.

Runs on your own device

100–300 MB

Typical memory use, about one busy browser tab. Ultra detail in multi-view mode uses more.

Seconds

Most models build in well under a second on a laptop. Carving runs in the background, so the page stays responsive.

Nothing uploaded

Drawings never leave your browser. A laptop is best for drawing and editing; phones work for viewing and quick checks.
